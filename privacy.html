Little Sprout

Privacy Policy

A plain-language summary based on the current Little Sprout project source and configuration.

1. Introduction

This policy describes how Little Sprout handles information when people use the app. Little Sprout is an early-learning app designed for children ages 2–3 and is available for Android and iOS.

2. About Little Sprout

Little Sprout contains learning activities for alphabet, numbers, colors, shapes, music, animals, birds, fruits, and vehicles. It includes parent-facing settings and progress views.

3. Information We Collect

The inspected app source records learning activity progress on the device. A progress record can include an activity identifier, category, play count, completion count, and timestamps for last played and last completed.

4. Information We Do Not Collect

Based on the Android manifest, iOS Info.plist, and project dependencies inspected for this version, the app does not declare camera, microphone, location, contacts, or network permissions. The project configuration does not include advertising, analytics, crash-reporting, or networking SDKs. No child account feature appears in the inspected source.

5. Children’s Privacy

The app is designed for young children. The inspected source stores learning progress and settings locally and does not show a child account or sign-in flow.

6. How Little Sprout Works

Learning content and audio are bundled with the app. The app provides interactive activity screens and a Today’s Adventure feature, which selects four learning categories for the current adventure.

7. Local Learning Progress

Learning progress is stored in local device storage through the app’s DataStore implementation. If you have enabled system-level backup (such as Google Drive backup for Android), this local data may be included in your device backups. The parent settings screen includes an option to reset this stored progress.

8. Audio and Media

The project bundles audio files used by learning activities and music features. The Android implementation uses device audio playback; the iOS implementation uses device audio playback. The inspected source does not request microphone access.

9. Third-Party Services

No third-party service that transmits user data was identified in the inspected app dependencies or platform configuration. The project uses development libraries such as Compose Multiplatform and AndroidX DataStore to run the app and store local preferences.

10. Advertising

No advertising SDK or advertising functionality was identified in the inspected project.

11. Analytics and Tracking

No analytics, tracking, or crash-reporting SDK was identified in the inspected project.

12. Internet and Network Access

The Android manifest does not declare internet access. No networking library or network service was identified in the inspected project configuration.

13. Device Permissions

The Android manifest for the inspected project does not declare device permissions. The iOS Info.plist does not include declared usage descriptions for camera, microphone, location, contacts, or photo library access.

14. Data Security

Progress and settings are stored locally on the device by the app. Device-level security is managed by the device and operating system. This project review did not identify a remote server handling app data.

15. Data Retention and Deletion

Local progress remains on the device until it is reset through the app’s settings or removed with the app’s local data. The app includes a Reset Progress action.

16. Changes to This Privacy Policy

If Little Sprout’s data handling changes, this policy should be updated before the changed version is published.
