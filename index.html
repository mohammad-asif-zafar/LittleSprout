Inside the app

Small activities, big moments of discovery

Tap through each learning area

Children can choose from the dashboard’s nine learning categories and view individual items within each area.

Listen as they learn

Item audio can be played during activities. Parent settings include sound, music, autoplay, and quiet-mode controls.

Keep an eye on progress

The parent area includes progress views for explored activities, songs played, and category progress, plus a reset option.

Today’s Adventure

A playful set of activities to try

Little Sprout’s Today’s Adventure presents four learning areas to explore. As an activity is started, it is marked as complete in the adventure.

  • Four categories are selected from the app’s learning areas.
  • Starting an included activity marks it in the current adventure.
  • A new adventure can be generated in the app.

Real user feedback & QA reports

Tester feedback & improvements

Real feedback reports and bug testing notes received during beta testing and how we resolved them.

💬

Beta Tester Report

Alphabet Locale Test (IMG_1718)

🔧 Bug Fixed

"Feedback from my sister: Why are letters showing in reverse (e.g. reading backwards like 'ELPPA') on certain device locales?"

✓ Resolution: Enforced global LTR text directionality to keep words reading correctly.

💬

Beta Tester Report

Numbers & Finger Count (IMG_1719)

🔧 Audio Verified

"Review on number finger counting: Make sure audio narration clearly reads out every single finger count and number for toddlers."

✓ Resolution: Verified touch card audio sync for all number gestures.

💬

QA Bug Report

Vehicle Text Sizing (IMG_1720)

🔧 UI Fixed

"Text overlap not looking good on vehicle and object labels (e.g., 'JEEP') when text sizing expands on smaller screens."

✓ Resolution: Implemented auto-shrinking text and layout bounds constraints.
